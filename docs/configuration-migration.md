# 명시적 설정으로 전환하기

이번 변경은 기존 노트·회고 원장·프로그램 기록을 삭제하거나 옮기지 않는다. 자동으로
설정 파일이나 설치된 스킬을 바꾸지도 않는다. 업데이트 전에 필요한 기능만 설정한다.
`~/.claude/agent-skills.json`이 이미 있으면 관련 키만 병합하고 `orchestrate` 등 다른 키를 보존한다.
아래 값은 자리표시자이므로 그대로 실행하거나 실제 목적지로 사용하지 않는다.

| 기능 | 설정이 없을 때 | 기존 동작을 계속 쓰려면 |
|---|---|---|
| 노트 | 목적지 미설정을 보고하고 결과를 현재 작업에 보관. 사용자가 목적지를 지정하기 전에는 외부 쓰기 없음 | `notes.adapter`와 해당 어댑터의 기존 목적지 설정 |
| 회고 | `reflect.ledger` 미설정을 보고하고 현재 작업에만 결과 표시 | 기존 원장의 경로를 그대로 지정. 편집할 원본 저장소는 `reflect.skill_repository` 지정 |
| 개인 폴더 정리 | `user_folders` 미설정 메모와 함께 건너뜀 | 승인한 폴더만 `reap.user_folders` 배열에 지정. 빈 배열이면 끔 |
| 성과 보고 | 시간대 기본값 UTC (`+00:00`) | 이전 `+09:00` 기준의 시간 표시·집계를 유지하려면 매 실행에 `--tz +09:00` 명시 |

예를 들어 기존 Obsidian 목적지와 원장을 계속 쓸 때 필요한 키의 형태는 다음과 같다.
이 예시는 폴더 정리를 활성화하지 않는다.

```json
{
  "notes": {"adapter": "obsidian", "obsidian": {"vault": "<기존 vault 이름>"}},
  "reflect": {
    "ledger": "<기존 원장 경로>",
    "skill_repository": "<스킬 원본 체크아웃 절대 경로>"
  },
  "reap": {"user_folders": []}
}
```

Markdown 저장소를 쓰면 `notes`를
`{"adapter":"markdown","markdown":{"root":"<기존 노트 루트>"}}` 형태로 지정한다.
과거 원장 형식과 source 값은 그대로 읽는다. 원장 내용의 치환이나 재작성은 필요 없다.
기존 정리 자동화의 `--under`와 지원하지 않는 `--kinds` 값은 이제 오류로 종료한다.
자동화 명령을 확인하고 지원하는 종류와 명시적 범위로 바꿀지는 사용자가 결정한다.
개인 경로나 과거 모델별 동작을 공통 기본값으로 되살리지 않는다.

설정 후에는 목적지와 원장을 읽어 기존 자료인지 확인하고, 개인 폴더 정리는 먼저
`scan --kinds user-folder`로 계획과 미설정 메모를 확인한다. 계획 확인만으로 삭제를
승인한 것은 아니다. 실제 정리는 기존 권한 범위와 재검사·휴지통 절차를 따른다.
